# Mulheres Luminosas — landing page

Landing page responsiva criada em HTML, CSS e JavaScript sem bibliotecas externas.

## Estrutura

- `index.html` — estrutura e conteúdo da página
- `css/styles.css` — identidade visual e layout responsivo
- `js/main.js` — menu mobile, prática interativa e perguntas frequentes
- `assets/` — logo e ilustrações incorporadas na página

## Abrir

Abra `index.html` em um navegador. Não é necessário instalar dependências ou iniciar um servidor.

## Interações

- Navegação adaptada para celular
- Dias da semana expansíveis
- Prática guiada “PARE · PERCEBA · ESCOLHA”
- Perguntas frequentes em acordeão
